# cs-skills
해당 레포는 CS 지식을 정리하고 사용 경험을 기록하기 위한 공간이다.
AI를 활용해 빠른 구현이 가능하지만 올바른 방향이 아니라면 빠른 속도는 토큰 낭비이다.
때문에 올바른 방향으로 지시하고 검증하기 위해서는 CS 지식은 여전히 중요하다.
이를 위해 나만의 CS 지식 노트를 만들고, 활용했던 경험을 기록한다.

## ground rules
```markdown
GROUND RULES
---
1. 공부한 CS 지식은 GitHub의 cs-skills repo에 md파일로 정리한다.
2. 알아보고, 이해를 하고, 암기를 하고 직접 타이핑한다.
3. 일주일에 3개 이상의 section을 정리한다.
4. 트러블 슈팅, 구현 설계 문서에 해당 cs 지식을 사용하는 경우 추가 작성한다.
5. 학습 내용은 아래 로드맵을 따라간다. 관심이 있는 주제가 있다면 우선 정리한다.
```
